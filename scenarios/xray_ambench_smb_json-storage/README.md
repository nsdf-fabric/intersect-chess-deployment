# Xray AMBench SMB JSON + Storage Scenario

This scenario runs the xray AMBench SMB JSON workflow plus MinIO and NSDF storage.

## Run

```bash
docker compose -f scenarios/xray_ambench_smb_json-storage/docker-compose.yml up -d --force-recreate
```

## Campaign payload
